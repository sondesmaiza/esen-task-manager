# 📝 ESEN Task Manager - Site Web

## 📖 Définition
**ESEN Task Manager** est un site web interactif conçu pour aider les étudiants à mieux organiser leurs tâches quotidiennes, leurs examens et leurs projets. C'est un outil pratique qui 
permet de centraliser toutes ses activités académiques au même endroit avec une interface simple et moderne.

---

## ✨ Fonctionnalités
* **Gestion des tâches :** Ajouter, modifier et supprimer des tâches facilement.
* **Organisation par priorité :** Les tâches sont triées par importance (Urgente, Moyenne, Faible).
* **Suivi de progression :** Possibilité de marquer les tâches comme "En attente" ou "Terminées".
* **Espace Membre :** Pages de connexion et d'inscription pour simuler un accès sécurisé.
* **Sauvegarde automatique :** Le site retient vos tâches et vos réglages grâce au stockage du navigateur.
* **Personnalisation :** Un menu permet d'activer une musique d'ambiance et de basculer en mode sombre.

---

## 🎨 Design & Ergonomie
* **Design Responsive :** Le site s'adapte parfaitement aux ordinateurs, tablettes et téléphones.
* **Style Moderne :** Utilisation des couleurs de l'ESEN, de boutons arrondis et de dégradés élégants.
* **Mode Sombre :** Une option pour passer tout le site en thème noir pour le confort des yeux.
* **Navigation Fluide :** Menu de navigation clair et animations lors du passage entre les pages.

---

## 🛠️ Technologies Utilisées
* **HTML5 :** Pour la structure des pages du site.
* **CSS3 :** Pour le design, les couleurs et les animations (Flexbox, Media Queries).
* **JavaScript :** Pour rendre le site vivant et gérer les actions de l'utilisateur.
* **LocalStorage :** Pour enregistrer les informations sans base de données externe.
* **Font Awesome & Google Fonts :** Pour les icônes et une belle écriture.

---
